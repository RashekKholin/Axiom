# Axiom

A free, local-first personal study platform.

## Current MVP

- Mobile-first PWA
- Local IndexedDB storage
- Subjects and topics
- Flashcards
- Practice-question-ready material type
- Notes and formulas as material types
- Add/delete material
- Flashcard study and rating
- Basic mastery and spaced review
- Progress dashboard
- JSON import/export
- Offline service worker

## Deployment

Deploy the repository root with GitHub Pages.

## Data

Study data is stored locally in the browser/device. Use Settings → Export JSON for backups.
